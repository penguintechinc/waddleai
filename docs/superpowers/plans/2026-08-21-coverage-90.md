**Branch:** `chore/coverage-90` (off `chore/v0.2-hardening`).

**Goal:** Close the honest gap Stage 0 exposed — `.coveragerc` now measures `shared` + `services/management/app` + `proxy` with `branch = True` and a pruned `omit` list (14 previously-hidden-but-tested files un-omitted, 6 stale entries for deleted files removed, `shared/utils/rag_integration.py` kept as a dated deliberate deferral). **Tech Stack:** Python 3.13, `pytest` + `pytest-asyncio` (`asyncio_mode = auto`), `.venv/bin/python -m pytest <path> -v` only — never host `python3`. `@dataclass(slots=True)` on any new test fixtures/doubles. Fixtures over unspec'd `MagicMock` — match each file's existing test-double pattern where one exists (`FakeDB`, `InMemoryX`) rather than inventing a new mocking style per file.

**Spec:** `.coveragerc` (this plan's config baseline) + `/tmp/claude-1000/-home-penguin-code-waddleai/43d1180f-41c8-4686-a7f4-b591781f586d/scratchpad/coverage-gap/coverage-plan.md` (Stage 0 audit this plan continues from).

## Global Constraints

- `.venv/bin/python` only (worktree venv) — never host/system `python3`.
- No network calls, no spaCy/Presidio/torch model downloads triggered by any new test — mock/stub at the HTTP-client or connector boundary, never let a real provider SDK call out.
- `@dataclass(slots=True)` for any new fixture/dataclass introduced by tests.
- Real fixtures/fakes over bare `MagicMock()` with no `spec=` — grep the target file's existing tests first; reuse its established double (e.g. `FakeDB` in management route tests, `InMemoryCredentialResolver`-style fakes) before inventing a new one.
- Each task's tests must pass under the CURRENT `.coveragerc` (`branch = True`, `fail_under` at whatever value that task's ratchet task last set) — run `.venv/bin/python -m pytest <new/changed files> -v` before moving to the next task, and `make test-unit` before each ratchet-click task.
- gRPC-touching files (`grpc_server.py`, `grpc/client.py`) mock the `grpc` channel/servicer context — never open a real socket.
- k8s-touching files (`ollama_manager.py`, `llamacpp_manager.py`) mock the k8s client (precedent: `test_llamacpp_manager_hardening.py`) — never hit a real cluster.

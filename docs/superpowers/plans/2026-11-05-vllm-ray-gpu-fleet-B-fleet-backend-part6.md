### Task B4b: shared/fleet/vllm_ray/tco.py

**Files:**
- Create: `shared/fleet/vllm_ray/tco.py`
- Create: `tests/unit/fleet/vllm_ray/test_tco.py`

**Interfaces:**
- Consumes: `Layout` (B4: `tensor_parallel`, `pipeline_parallel`, `replicas`, `nodes_used`, `gpu_class`), `PriceMode` (B1), `GPU_PRICE_REFERENCE` (B4c).
- Produces (AM6, exact), all `@dataclass(slots=True)`:
  - `NodeClassCost(cpu_usd: float, ram_gb: int, nvme_gb: int, nvme_pro: bool, network_devices: int, node_base_watts: int, gpus_per_node: int, node_base_usd: float | None = None)` (explicit override).
  - `GpuClassCost(gpu_class: str, card_usd: float | None, tdp_watts: int | None, est_tokens_per_s: float, node: NodeClassCost)`; `None` for `card_usd` / `tdp_watts` resolves from the reference (AM8, rule below).
  - `TcoInputs(kwh_usd: float = 0.18, lifecycle_years: int = 10, utilization_pct: int = 50, input_ratio: float = 0.2, ram_usd_per_gb: float = 1.0, nvme_usd_per_gb: float = 1.0, nvme_pro_usd_per_gb: float = 2.0, network_device_usd: float = 400.0)`.
  - `TcoResult(hourly_cost_usd, gpu_hourly_usd, node_hourly_usd, node_base_usd, tokens_per_s_used, source, price_input_per_1m, price_output_per_1m, breakdown: dict)`; `source` is `"observed"` or `"estimate"`.
  - `node_base_usd(node: NodeClassCost, inputs: TcoInputs) -> float`: explicit `node.node_base_usd` wins, else `cpu_usd + ram_gb*ram_usd_per_gb + nvme_gb*(nvme_pro_usd_per_gb if nvme_pro else nvme_usd_per_gb) + network_devices*network_device_usd`.
  - `compute_tco(layout: Layout, costs: dict[str, GpuClassCost], inputs: TcoInputs, params_b: float, observed_tokens_per_s: float | None) -> TcoResult`; `costs` is keyed by `layout.gpu_class`.

Formulas (spec §4.7, verbatim; `lifecycle_hours = lifecycle_years*365*24`):

- `total_gpus = tensor_parallel * pipeline_parallel * replicas`; `gpus_used_on_node = total_gpus / nodes_used`.
- `gpu_hourly = total_gpus * (card_usd/lifecycle_hours + tdp_watts/1000*kwh_usd)`.
- `node_hourly = nodes_used * (gpus_used_on_node/gpus_per_node) * (node_base_usd/lifecycle_hours + node_base_watts/1000*kwh_usd)`.
- `hourly_cost = gpu_hourly + node_hourly`; `tokens_per_s_used` = observed when not None (source `"observed"`), else `est_tokens_per_s * min(1, 12/params_b)` (source `"estimate"`).
- `price_output_per_1m = hourly_cost / (tokens_per_s_used*3600*utilization_pct/100) * 1e6`; `price_input_per_1m = price_output_per_1m * input_ratio`.
- `kwh_usd <= 0` raises `ValueError("kwh_usd must be set")` (checked first); `breakdown` records the per-term values (card amortization, GPU power, node share, assumed throughput, inputs used). Each function gets a 2-3 line docstring.
- **Reference fallback (AM8).** Per class: `card_usd is None` → `GPU_PRICE_REFERENCE[gpu_class].avg_street_usd`; `tdp_watts is None` → `GPU_PRICE_REFERENCE[gpu_class].tdp_watts`. A `None` whose class is missing from the reference → `ValueError(f"no price reference for {gpu_class}; set cost.cardUsd and cost.tdpWatts")`. Explicit values always override the reference. `breakdown["price_source"]` = `"configured"` when both values are explicit, else `"reference"`.

**Interfaces:**
- Consumes: `LocalDeploymentKind`, `PriceMode` (B1); `Layout` (B4); `compute_tco`, `TcoInputs`, `GpuClassCost`, `NodeClassCost`, `TcoResult` (B4b); ORM rows `VllmDeployment`, `OllamaDeployment`, `LlamaCppDeployment`, `ModelRegistry` (B2); the `TokenConversionRate` ORM model (`services/management/app/models_sqlalchemy.py:547`, table `token_conversion_rates`).
- Produces (AM10 signatures; two clarifications marked ◆):
  - `def gpu_set_for(kind: int, row: Any) -> tuple[list[tuple[str, int]], NodeClassCost | None]`. The second element is always `None` in this contract ◆: the node cost is resolved by `apply_pricing` from `costs[gpu_class].node`.
    - VLLM: `[(row.gpu_class, row.tensor_parallel * row.pipeline_parallel * row.replicas_min)]`. ◆ Committed capacity only; burst replicas are not priced.
    - OLLAMA / LLAMACPP: class = value of key `waddleai.penguintech.io/gpu-classes` in the deployment's node selector (llama.cpp: `row.node_selector`; Ollama: `row.gpu_config["node_selector"]`). Count = `row.gpu_count` (llama.cpp) or `row.gpu_config["gpu_count"]` (Ollama), default 1. Missing label → `ValueError("deployment has no waddleai.penguintech.io/gpu-classes node selector; cannot price")`.
    - Unknown kind → `ValueError`.
  - `async def apply_pricing(db, kind: int, row: Any, inputs: TcoInputs, costs: dict[str, GpuClassCost], observed_tokens_per_s: float | None) -> TcoResult | None`. ◆ Returns `None` for MANUAL (no TCO is computed).
    - MANUAL (`row.price_mode == PriceMode.MANUAL`): `price_input_per_1m` and `price_output_per_1m` must be finite and > 0, else `ValueError`. `price_breakdown` is left untouched.
    - AUTO: one GPU class per deployment (◆ mixed-class priced deployments are refused with `ValueError("AUTO pricing needs one GPU class per deployment")`; Open item). `costs[gpu_class]` missing → `ValueError(f"no cost config for {gpu_class}")`. `nodes_used = ceil(total_gpus / costs[cls].node.gpus_per_node)` ◆. `params_b` from `model_registry.params_b` for the row's model (AM4); NULL → `ValueError("set model params_b before AUTO pricing")`. `layout = Layout(vendor, gpu_class, replicas=1, tensor_parallel=..., pipeline_parallel=..., strategy=1, nodes_used, 0, 0, True, "")` built from the gpu set. ◆ Non-vLLM kinds use `pipeline_parallel=1`, `tensor_parallel=count`, `nodes_used=1`.
    - `result = compute_tco(layout, {cls: costs[cls]}, inputs, params_b, observed_tokens_per_s)`.
    - Writes `row.price_input_per_1m` / `row.price_output_per_1m` = result values, `row.price_breakdown = result.breakdown`, and `row.observed_tokens_per_s` when not None.
    - Upserts the rate row via `upsert_virtual_rate(db, provider, model, price_input_per_1m, price_output_per_1m)` (imported from C6, see Interfaces; `Decimal` arguments). `provider`: VLLM → `"vllm"`, OLLAMA → `"ollama"`, LLAMACPP → `"llamacpp"`. `model` = served name: vLLM `served_model_name`; Ollama `name` ◆ (executor verifies it equals the model string clients send); llama.cpp `model_name`.
  - `def load_pricing_inputs(config: dict[str, Any]) -> tuple[TcoInputs, dict[str, GpuClassCost]]` (AM21; consumed by C2/C2b/C3/F5). Reads `config["tco"]` (snake_case `TcoInputs` fields; absent → defaults; unknown key → `ValueError`) and `config["worker_groups"]` (list of `{"gpu_class": str, "cost": {"card_usd": float | None, "tdp_watts": int | None, "est_tokens_per_s": float, "node": {<NodeClassCost fields, incl. gpus_per_node>}}}`). Missing `gpu_class`, `est_tokens_per_s`, or `node`, or a duplicate `gpu_class` → `ValueError`. Returns costs keyed by `gpu_class`.
  - `def virtual_rates(price_input: float, price_output: float, base_cost_per_waddleai_token: float) -> tuple[Decimal, Decimal]` returns `base × 1e6 / price` for each (AM2 divisor convention). A price ≤ 0 → `ValueError`.
  - `upsert_virtual_rate` is NOT defined here. `apply_pricing` imports it inside the function from `shared.quota.virtual_price` (Plan C task C6 owns it): `upsert_virtual_rate(db, provider: str, model: str, price_input_per_1m: Decimal, price_output_per_1m: Decimal) -> None`. The unit tests patch `shared.quota.virtual_price.upsert_virtual_rate`.

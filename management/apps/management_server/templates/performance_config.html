About XDP: XDP (eXpress Data Path) provides kernel-level packet processing for:
  • DDoS protection at packet level
  • Hardware-accelerated rate limiting
  • 10-100x performance improvement for high-throughput scenarios
  • Zero-copy AF_XDP sockets for WebSocket streaming
Requirements:
  • Linux kernel 5.10+
  • Root privileges or CAP_NET_ADMIN capability
  • Network interface with XDP support
  • Compiled BPF program (xdp_filter.o)

Performance Tips
Optimizing XDP Performance:
  1. Use native mode: Change XDP_MODE from 'skb' to 'native' for better performance
  2. Enable hardware offload: Use 'offload' mode if your NIC supports it
  3. Tune rate limits: Configure per-IP rate limits in the XDP BPF map
  4. Monitor metrics: Track packet statistics to identify bottlenecks
  5. Use AF_XDP: Enable AF_XDP sockets for WebSocket connections
Environment Variables:
ENABLE_XDP=true
XDP_INTERFACE=eth0
XDP_PROGRAM_PATH=/app/shared/networking/xdp_filter.o
XDP_MODE=native  # or 'skb' or 'offload'

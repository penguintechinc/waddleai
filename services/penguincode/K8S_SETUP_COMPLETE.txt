QUICK START COMMANDS
================================================================================

Deploy to Alpha (Testing):
  kubectl apply -k k8s/kustomize/overlays/alpha

Deploy to Beta (Production-like):
  ./scripts/deploy-beta.sh
  OR
  kubectl apply -k k8s/kustomize/overlays/beta

View Deployment:
  kubectl get pods -n penguincode-beta
  kubectl logs -n penguincode-beta -l app=penguincode

Test Health:
  kubectl port-forward -n penguincode-beta svc/penguincode-server 8080:8080
  curl http://localhost:8080/api/v1/health

Rollback:
  ./scripts/deploy-beta.sh --rollback penguincode-1

Dry Run:
  ./scripts/deploy-beta.sh --dry-run

CLI Options:
  --tag <tag>             Custom image tag (default: beta-YYYYMMDD-HHMMSS)
  --service <service>     Deploy specific service
  --skip-build            Skip Docker build and push
  --dry-run              Show what would be deployed
  --rollback <release>   Rollback to previous release
  --verbose              Enable verbose output
  --help                 Show help message

Workflow:
  1. Prerequisite check (docker, kubectl, helm, context)
  2. Generate or use provided image tag
  3. Build Docker image
  4. Push to registry (dai2-beta)
  5. Deploy with Helm (values-beta.yaml overrides)
  6. Verify deployment and health
  7. Display summary
